# Healthcare Performance and Patient Outcome Analysis

## Project Overview
A six-week healthcare data analytics and visualization
project focused on hospital performance monitoring.

## Objectives
- Analyze patient visits and admissions.
- Monitor department workload.
- Evaluate waiting times.
- Track bed occupancy.
- Analyze readmission rates and patient outcomes.
- Develop an interactive Power BI dashboard.

## Tools
- Excel
- SQL / MySQL
- Python
- Pandas
- Power BI

## Project Duration
6 Weeks
